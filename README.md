# KASANGGA

**KASANGGA: A Mobile-Based Violence Against Women and Children (VAWC) Reporting and Assistance System with Web-Based Admin Dashboard**

A capstone project by Team INNOTRIX (BSIT 4B), College of Informatics and Computing Innovations, Iloilo State University of Fisheries Science and Technology – San Enrique Campus, 2026.

This website presents the full manuscript (Chapters I–V, references, and Appendices A–N) and the final defense slides. Every section links to its matching slides, and every slide links back to the manuscript.

Open `index.html` in a browser, or view it on GitHub Pages.
